# Scaling Law

This category is named as `Scaling Law` for the publications listed do the same thing with the previous Deep Learning Recommendation System (DLRM): 
predict score for items, instead of generating an item.

They basically re-construct model architecture using `Transformers`, which contributes to the parameters and computation scaling.
